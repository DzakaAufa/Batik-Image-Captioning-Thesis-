# proyek_gpu

Proyek machine learning / deep learning menggunakan GPU server FILKOM UB.

## Struktur
- dzakanenv/        : Virtual environment (opt and flan)
- dzakaenv/         : QWEN
- capenv/           : Caption (Internvl)
- evalenv/          : evaluation
- data/             : Dataset
- evaluation_resutls/: hasil evaluasi
- java_libs/        : library java untuk evaluasi
- logs/             : logs hasil run code
- models/           : saved models
- notebooks/        : Eksperimen Jupyter
- src/              : Source code
- requirements.txt/ : Dependency
